What problem are we solving?
I am solving the problem of digital finance, where users can engage in financial transactions from one account to another. Receive and send digital money basically.

who are our users
User
Admin

what can a user do?
Register
Login
Create wallet
View balance
Deposit
Withdraw
Transfer
View transactions

what must never happen?
Money disappearing
Negative balances
Duplicate transfers
Unauthorized transfers
Two users receiving the same money
A transaction being recorded without the balance changing
A balance changing without a transaction record

What does success mean?
A user should be able to securely transfer funds to another user while maintaining a consistent financial ledger.
